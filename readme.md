# Staf.ai - Gerador de Backlog Automático

Aplicação Full Stack que utiliza Inteligência Artificial para ler documentos PDF de projetos e gerar automaticamente cards (Tarefas) no JIRA.

## 🚀 Tecnologias Utilizadas

- **Frontend:** Angular 18+, Angular Material
- **Backend:** Node.js, Express
- **Integração:** Google Gemini API (IA), JIRA REST API
- **Processamento de Arquivos:** Multer, PDF-Parse
